Projeto Completo — UpPay Connect
UpPay Connect
Pagamentos integrados, simples e inteligentes.
1. Visão geral do projeto

O UpPay Connect será a infraestrutura central de pagamentos da UpFive7, responsável por conectar todos os sistemas internos da empresa a parceiros financeiros como Asaas e PagBank.

O objetivo não é, inicialmente, criar um gateway público para terceiros. O objetivo é criar uma API interna padronizada, onde todos os sistemas da UpFive7 consigam gerar cobranças, consultar pagamentos, receber confirmações, controlar assinaturas, emitir links de pagamento e automatizar status financeiros sem precisar integrar individualmente com cada banco ou provedor.

2. Posicionamento do produto
Nome
UpPay Connect
Slogan
Pagamentos integrados, simples e inteligentes.

A infraestrutura de pagamentos dos sistemas UpFive7.
Descrição completa
O UpPay Connect centraliza os pagamentos dos sistemas da UpFive7 em uma única API, conectando agendamentos, CRMs, automações, cobranças e plataformas digitais ao Asaas e PagBank de forma simples, segura e inteligente.

Exemplo prático

Um cliente agenda um serviço pelo sistema de agendamento.

1. Sistema de agendamento cria uma cobrança no UpPay Connect
2. UpPay Connect gera Pix, boleto ou link de pagamento
3. Cliente recebe a cobrança
4. Cliente realiza o pagamento
5. Asaas ou PagBank confirma o pagamento
6. UpPay Connect recebe o webhook
7. UpPay Connect atualiza a transação
8. Sistema de agendamento é avisado
9. Agendamento é confirmado automaticamente

14. Criar pagamento
Endpoint
POST /v1/payments
Header obrigatório
Authorization: Bearer sk_live_xxxxxxxxxxxxxxxxx
Idempotency-Key: pedido-1024
Payload padrão
{
  "amount": 15000,
  "currency": "BRL",
  "payment_method": "pix",
  "description": "Agendamento #1024",
  "customer": {
    "name": "João Silva",
    "email": "joao@email.com",
    "document": "12345678900",
    "phone": "11999999999"
  },
  "external_reference": "agenda_1024",
  "source_system": "up_schedule",
  "callback_url": "https://agenda.upfive7.com/webhooks/payments",
  "expires_in": 3600
}
Regras importantes
- amount sempre em centavos
- currency padrão: BRL
- source_system identifica qual sistema criou a cobrança
- external_reference identifica a cobrança no sistema de origem
- callback_url é a URL para avisar o sistema de origem
- Idempotency-Key evita cobranças duplicadas

19. Roteamento de pagamento

Criar o serviço:

PaymentRouterService

Esse serviço decide qual parceiro processará a cobrança.

Regras iniciais
Se payment_method = pix:
usar Asaas

Se payment_method = boleto:
usar Asaas

Se payment_method = subscription:
usar Asaas

Se payment_method = credit_card:
usar PagBank

Se payment_method = debit_card:
usar PagBank

Se payment_method = payment_link:
usar PagBank

Se payment_method = checkout:
usar PagBank
Regras futuras
- Escolher provedor por menor taxa
- Escolher provedor por disponibilidade
- Escolher provedor por sistema de origem
- Escolher provedor por valor da cobrança
- Escolher provedor por tipo de cliente
- Aplicar fallback automático

Todos os eventos enviados para os sistemas internos devem ter assinatura.

x-uppay-event: payment.paid

Segurança obrigatória

- Proteção contra replay attack
- Registro de entrega

56. Prompt completo para criar o projeto
Crie um sistema SaaS interno chamado UpPay Connect.

Slogan:
Pagamentos integrados, simples e inteligentes.

O UpPay Connect será a infraestrutura central de pagamentos da UpFive7.

O sistema deve centralizar pagamentos dos sistemas próprios da empresa, como sistema de agendamento, CRM WhatsApp, CRM empresarial, sistemas de assinatura e futuros SaaS.

O objetivo não é criar inicialmente um gateway público para terceiros.
O objetivo é criar uma API interna segura e padronizada para que todos os sistemas da UpFive7 possam criar cobranças, consultar pagamentos, receber confirmações, controlar assinaturas, gerar Pix, boleto, link de pagamento, cartão e eventos financeiros.

A API deve se integrar inicialmente com dois provedores financeiros:
1. Asaas
2. PagBank

Uso dos provedores:
- Asaas para Pix, boleto, mensalidades, assinaturas e recorrência.
